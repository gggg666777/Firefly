连接仓库

只剩一件事：填访问令牌

仓库、分支、目录已经按你的博客预填好了。你只需要去 GitHub 生成一个令牌粘进来。信息只存在你手机里，不会上传到任何地方。

怎么拿到 Token

  1. 手机浏览器打开 github.com/settings/personal-access-tokens/new
  2. Token name 随便填，Expiration 选 1 年（到期再换）
  3. Repository access 选 Only select repositories，只勾 gggg666777/Firefly
  4. Permissions 展开 Repository permissions，找到 Contents，改成 Read and write
  5. 点最下面 Generate token，复制那串以 github_pat_ 开头的字符

这个令牌只能动你这一个仓库，泄露了也伤不到别的项目。但别截图发群里。
